# Repository Instructions

- Use backtick inline code for function names, language constructs, operators,
  command names, file names, and similar technical tokens. For example, write
  `printf()`, `operator<<`, `pthread_mutex_lock()`, `int`, and `gcc`.
- Do not use backtick inline code for ordinary prose names of programming
  languages, libraries, products, or technologies unless the text refers to a
  literal syntactic token, command, package name, or file name.
- Keep Markdown prose in essays wrapped to 80 characters where practical.
- Do not reflow front matter, code fences, raw HTML blocks, Hugo shortcodes,
  images, or headings just to satisfy the line length rule.
